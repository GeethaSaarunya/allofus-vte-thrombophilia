# Release checklist

## Before creating GitHub release v1.0.0

- [x] Generate and add the count-free VTE concept specification and QC/source-discovery audit.
- [x] Generate and add the count-free clinical-risk concept specification and QC/source-discovery audit.
- [ ] Confirm no participant-level files are present.
- [ ] Re-run the small-cell audit.
- [ ] Replace any journal DOI placeholder in `CITATION.cff`.
- [ ] Add repository URL to `CITATION.cff` after the GitHub repository exists.
- [ ] Confirm author names/affiliations and ORCIDs if desired.
- [ ] Select repository/license terms.
- [ ] Tag `v1.0.0`.
- [ ] Create a GitHub Release from `v1.0.0`.
- [ ] Archive the release in Zenodo or publish the prepared manual Zenodo deposit.
- [ ] Add the final Zenodo DOI back to the manuscript Data Availability statement.
