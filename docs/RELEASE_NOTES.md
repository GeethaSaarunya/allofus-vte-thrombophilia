# v1.0.1 — Documentation and packaging correction

This maintenance release corrects the public repository packaging for the All of Us VTE clinical-genetic burden reproducibility materials.

- Restores `.gitignore` and `.github/workflows/validate.yml`, which were omitted during the v1.0.0 browser upload.
- Removes the duplicate provenance section at the end of the README, retaining the approved concise paragraph and its link to detailed reproducibility notes.
- Regenerates the checksum manifest for the actual release contents.
- Updates citation metadata to version 1.0.1 and adds the repository URL and all-versions Zenodo identifier.

Scientific analysis scripts, aggregate source results, figures, phenotype specifications, and environment files are unchanged from v1.0.0. Historical source-discovery and quality-control records are retained.

Previous release: [v1.0.0](https://github.com/GeethaSaarunya/allofus-vte-thrombophilia/releases/tag/v1.0.0), archived at [10.5281/zenodo.22715380](https://doi.org/10.5281/zenodo.22715380).

The v1.0.1 version DOI is assigned when Zenodo archives this release. The [all-versions DOI](https://doi.org/10.5281/zenodo.22715379) identifies the release series.
